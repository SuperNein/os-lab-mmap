# Файловые системы. File mapping

**Лабораторная работа 4**

---

**Тема:** Обеспечение обмена данных между процессами посредством технологии «File mapping»

**Условие:** Родительский процесс создает два дочерних процесса. Взаимодействие между процессами осуществляется через разделяемую память.

**Вариант:** Строки длины больше 10 символов отправляются в child2, иначе в child1. Дочерние процессы инвертируют строки.

---

## Сборка и запуск

### Требования

* Компилятор C++20
* CMake 3.16+

### 1. Конфигурация проекта

Создание папки сборки `build` и установка зависимостей:

```Bash
cmake -B build
```

### 2. Компиляция

```Bash
cmake --build build
```

### 3. Запуск

#### Основная программа

```Bash
./build/parent
```
